# Incendios España

Proyecto para publicar automáticamente los incendios activos de España utilizando datos de NASA FIRMS.

## Características

- Actualización automática cada 8 horas.
- Datos oficiales NASA FIRMS.
- Filtrado únicamente de España.
- Compatible con Google Earth.
- Iconos personalizados de gran tamaño.

Creado con GitHub Actions.
